Counts are occurrences, not distinct or working endpoints. URL and path candidates include SDKs, unused code, documentation, and non-network paths. Each candidate records its APK, DEX member, string index, and byte offset. URL userinfo, query strings, and fragments are omitted. No HTTP methods are assigned to lexical candidates.

## Reproduce

Place your own matching base and split APKs in `apps/discord/apks/`, with the acquisition receipt generated by the existing pull helper. Both APKs and the receipt remain ignored by Git. From the repository root:

```sh
python3 apps/instagram/scripts/pull-apks.py --package com.discord --output apps/discord/apks
python3 scripts/analyze-apks.py discord
python3 scripts/test_analyze_apks.py
python3 scripts/check-public.py
```

Acquisition requires an authorized Android device and `adb`; discovery needs Python 3.10+, Java, and Android SDK `apkanalyzer` on PATH. The pull helper refuses to overwrite an existing snapshot. The analyzer verifies every input against its receipt before replacing the discovery report. New APK versions produce different results and must be reviewed independently.

## Selected Hermes tracing

[hermes-trace.json](evidence/hermes-trace.json) records Hermes **v98**, 158,673 function headers, 344,868 strings, and 50 functions with decoded references to selected API-base or account-route strings. The 148 functions selected by a byte prefilter decoded without reported errors; that does not validate the entire bundle. `/users/@me/settings` exists in the string table but was not established as a decoded instruction operand by this pass.

Function 24327 (`getAPIBaseURL`, bundle offset 28,848,610) builds a base from `https:` and `window.GLOBAL_ENV.API_ENDPOINT`, adding `/v` plus `API_VERSION` when requested. Function 78989 (`prepareRequest`, offset 42,169,127) prefixes a slash-leading request URL with that base. Its selected listing also inspects authorization header keys; no credential values were extracted.

The external parser explicitly warns that v98 is **not formally supported**. These are provisional decoded code observations, not validated runtime requests. Next: independently cross-check the v98 decoding and follow endpoint constants through the HTTP wrapper and call sites, including serialized object literals.

## Initial investigation plan

Decode the Hermes bundle in `assets/index.android.bundle`, locate API base URL and route constants, then trace its request wrapper and method selection. The DEX scan does not cover this bytecode.

This pass reads DEX identifiers and annotations and inventories code assets. It does not decode method bodies, native code, JavaScript/Hermes bytecode, dynamic routes, or server-driven behavior. No app launch, account-storage access, or API request was performed. Zero recognized annotations does not mean the app has no API calls.

The project originally used [REA](https://github.com/morluto/rea) for Instagram analysis. This discovery pass uses the checked-in Python script and Android SDK manifest reader; it does not claim REA decompilation of these four apps.
