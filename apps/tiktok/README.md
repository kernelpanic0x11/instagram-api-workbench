Status: discovery and selected static tracing completed; no runtime verification or authenticated app workbench yet.

Counts are occurrences, not distinct or working endpoints. URL and path candidates include SDKs, unused code, documentation, and non-network paths. Each candidate records its APK, DEX member, string index, and byte offset. URL userinfo, query strings, and fragments are omitted. No HTTP methods are assigned to lexical candidates.

## Reproduce

Place your own matching base and split APKs in `apps/tiktok/apks/`, with the acquisition receipt generated by the existing pull helper. Both APKs and the receipt remain ignored by Git. From the repository root:

```sh
python3 apps/instagram/scripts/pull-apks.py --package com.zhiliaoapp.musically --output apps/tiktok/apks
python3 scripts/analyze-apks.py tiktok
python3 scripts/test_analyze_apks.py
python3 scripts/check-public.py
```

Acquisition requires an authorized Android device and `adb`; discovery needs Python 3.10+, Java, and Android SDK `apkanalyzer` on PATH. The pull helper refuses to overwrite an existing snapshot. The analyzer verifies every input against its receipt before replacing the discovery report. New APK versions produce different results and must be reviewed independently.

## Selected DEX and native tracing

[dex-trace.json](evidence/dex-trace.json) links three selected route annotations and four referencing methods, with 241,578 methods decoded in target-containing DEX files and no reported decode errors. [request-factory-trace.json](evidence/request-factory-trace.json) follows the obfuscated `LX/050z` annotation through `RequestFactory.parseAnnotations` into the builder's method/path fields and then `RequestFactory.httpMethod` / `relativeUrl`.

The manually reviewed [mapping evidence](evidence/request-mapping-review.json) establishes **GET client declarations** for `/aweme/v1/notice/count/`, `/tiktok/comment/status/batch_get/v1`, and `/aweme/v1/aweme/detail/`. The detail declaration resides in a split APK. The mapping is bound to the recorded APK hashes. Host binding, actual invocation, payload/query schemas, later interceptors, authentication and server behavior remain unresolved.

[native-bridges.json](evidence/native-bridges.json) records selected Cronet request entry points and HTTP-method parameter getter/setter exports in `libsscronet.so`. Exports alone do not connect these three declarations to native dispatch.

Next: trace parameter annotations, the Retrofit service host, request interceptors and final dispatch. Expand annotation extraction only after validating the mapping against additional examples and negative cases.

## Initial investigation plan

Find DEX references to `/aweme/v1/aweme/detail/` and `/tiktok/comment/status/batch_get/v1`, identify the obfuscated request annotations or builder, and trace serialization. Treat unclassified `.so` assets as opaque until their formats are identified.

This pass reads DEX identifiers and annotations and inventories code assets. It does not decode method bodies, native code, JavaScript/Hermes bytecode, dynamic routes, or server-driven behavior. No app launch, account-storage access, or API request was performed. Zero recognized annotations does not mean the app has no API calls.

The project originally used [REA](https://github.com/morluto/rea) for Instagram analysis. This discovery pass uses the checked-in Python script and Android SDK manifest reader; it does not claim REA decompilation of these four apps.
