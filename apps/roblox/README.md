Counts are occurrences, not distinct or working endpoints. URL and path candidates include SDKs, unused code, documentation, and non-network paths. Each candidate records its APK, DEX member, string index, and byte offset. URL userinfo, query strings, and fragments are omitted. No HTTP methods are assigned to lexical candidates.

## Reproduce

Place your own matching base and split APKs in `apps/roblox/apks/`, with the acquisition receipt generated by the existing pull helper. Both APKs and the receipt remain ignored by Git. From the repository root:

```sh
python3 apps/instagram/scripts/pull-apks.py --package com.roblox.client --output apps/roblox/apks
python3 scripts/analyze-apks.py roblox
python3 scripts/test_analyze_apks.py
python3 scripts/check-public.py
```

Acquisition requires an authorized Android device and `adb`; discovery needs Python 3.10+, Java, and Android SDK `apkanalyzer` on PATH. The pull helper refuses to overwrite an existing snapshot. The analyzer verifies every input against its receipt before replacing the discovery report. New APK versions produce different results and must be reviewed independently.

## Selected native tracing

[native-trace.json](evidence/native-trace.json) identifies an ARM64 ELF and records 2,249 selected first-party URL or HTTP-related constant occurrences and 3,175 adjacent `ADRP`/`ADD` address-forming references. Some constants are documentation, telemetry or test URLs; these counts are not endpoint counts. Eight references address the literal `HttpService`.

Selected excerpts are independently disassembled with LLVM, retaining virtual addresses and instruction words. For example, `0x205e380` forms an address of `HttpService`. Exported JNI symbols also include the HTTP-client proxy-setting bridge. Address formation and exported names do not prove a request was sent or recover a function's complete behavior.

Next: delimit the functions around selected references, trace calls and request-object fields, and distinguish initialization constants from active request construction.

## Initial investigation plan

Trace DEX references to `/notifications/v1/push-receive-ack` and inspect `lib/arm64-v8a/libroblox.so` for the native networking layer. A DEX-only catalog leaves native request construction unresolved.

This pass reads DEX identifiers and annotations and inventories code assets. It does not decode method bodies, native code, JavaScript/Hermes bytecode, dynamic routes, or server-driven behavior. No app launch, account-storage access, or API request was performed. Zero recognized annotations does not mean the app has no API calls.

The project originally used [REA](https://github.com/morluto/rea) for Instagram analysis. This discovery pass uses the checked-in Python script and Android SDK manifest reader; it does not claim REA decompilation of these four apps.
