Counts are occurrences, not distinct or working endpoints. URL and path candidates include SDKs, unused code, documentation, and non-network paths. Each candidate records its APK, DEX member, string index, and byte offset. URL userinfo, query strings, and fragments are omitted. No HTTP methods are assigned to lexical candidates.

## Reproduce

Place your own matching base and split APKs in `apps/snapchat/apks/`, with the acquisition receipt generated by the existing pull helper. Both APKs and the receipt remain ignored by Git. From the repository root:

```sh
python3 apps/instagram/scripts/pull-apks.py --package com.snapchat.android --output apps/snapchat/apks
python3 scripts/analyze-apks.py snapchat
python3 scripts/test_analyze_apks.py
python3 scripts/check-public.py
```

Acquisition requires an authorized Android device and `adb`; discovery needs Python 3.10+, Java, and Android SDK `apkanalyzer` on PATH. The pull helper refuses to overwrite an existing snapshot. The analyzer verifies every input against its receipt before replacing the discovery report. New APK versions produce different results and must be reviewed independently.

## Selected DEX and native tracing

[dex-trace.json](evidence/dex-trace.json) records four referencing methods for three selected literals, with 82,292 methods decoded in the target-containing DEX files and no reported decode errors. In `Lpf3.subscribe`, `targetingQuery` is passed to `UnifiedGrpcService.unaryCall` following a protobuf-to-buffer helper. The route load is at `classes.dex`, byte offset 5,431,062; the call follows at 5,431,066.

`GenerateCaption` is also used alongside `MessageNano.toByteArray` and the `Lwed.a` wrapper. `/loq/register_v2` appears in a static set initializer; this pass does not establish that registration request execution occurs.

[native-bridges.json](evidence/native-bridges.json) records the matching exported `UnifiedGrpcService` JNI unary-call entry point at `0xc95784` in `libclient.so`, plus create and streaming-call symbols. Only selected native entry-point instructions are disassembled; the complete native gRPC implementation and payload schemas remain untraced.

Next: follow the unary-call options and protobuf field encoders, then inspect the corresponding native bridge implementation. Do not classify RPC service names as REST endpoints without further evidence.

## Initial investigation plan

Trace `/loq/register_v2` and the `snapchat.*Service/Method` literals to their call sites. Determine HTTP versus RPC transport and message schemas from code; slash-delimited service names alone do not establish REST endpoints.

This pass reads DEX identifiers and annotations and inventories code assets. It does not decode method bodies, native code, JavaScript/Hermes bytecode, dynamic routes, or server-driven behavior. No app launch, account-storage access, or API request was performed. Zero recognized annotations does not mean the app has no API calls.

The project originally used [REA](https://github.com/morluto/rea) for Instagram analysis. This discovery pass uses the checked-in Python script and Android SDK manifest reader; it does not claim REA decompilation of these four apps.
